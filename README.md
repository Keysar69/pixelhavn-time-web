# PixelHavn Time — iPhone web app

Built app files only (no data, no source). Source is kept in a private repository.

**Install on iPhone:** open https://keysar69.github.io/pixelhavn-time-web/ in **Safari** → Share → **Add to Home Screen** → always open it from the icon.

All hours and rates are stored only on each phone. Nothing is sent to any server. Export a backup from Settings regularly.
